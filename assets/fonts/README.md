# Fuentes locales

Cormorant Garamond (redonda y cursiva) y Manrope, bajo SIL Open Font License 1.1. Los avisos de autor y las referencias originales se conservan en los archivos `*-LICENSE.txt`; el texto íntegro de la licencia está en `OFL.txt`.

Copias obtenidas de las fuentes preinstaladas en el entorno. Se han reducido a los caracteres latinos, acentos y puntuación utilizados por la web con FontTools. No requieren servicio externo ni paso de build. Se conservan los ejes variables y los metadatos de autoría.
